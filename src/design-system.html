01

Principles

Four rules that settle most design arguments before they start.

{{icon:leaf:20}}

Earned, not decorative

Every animation, gradient and illustration has to do a job — direct attention, show state, or explain a process. Ornament that does none of those gets cut.

{{icon:eye:20}}

Legible before beautiful

Body text never falls below 16px, at any viewport width, and never below 4.5:1 contrast. If a design choice fights readability, readability wins.

{{icon:layers:20}}

One system, no exceptions

No page-specific stylesheets. If a page needs something new, it becomes a component here first.

{{icon:target:20}}

Honest about the numbers

Data components are built to show shortfalls as clearly as successes. A progress meter at 40% must look like 40%.

02

Colour

Three families: leaf greens carry the brand, lime is the single accent reserved for action, and warm papers hold the page together. Clay appears only to represent degraded land. The greens are deliberately olive rather than emerald — the colour of a hedgerow in July, not a logo.

Forest

Lime — action only

Neutrals

{{icon:eye:16}} Measured on the paper background: body text 16.0:1, muted text 5.4:1, breadcrumbs and footer meta 4.6:1, green buttons 6.3:1, and lime buttons carrying forest-900 text at 12.5:1. Every text pairing clears 4.5:1 in both themes. Lime is never used for text on a light surface — it fails at every size.

Semantic tokens

Components only ever reference these. Swapping the theme redefines the semantic layer, never the components.

03

Typography

Plus Jakarta Sans carries everything — interface, headlines and figures — with an old-style serif reserved for quotations and a mono for data. It is self-hosted as a single variable file (400–800), so there are no third-party requests and no flash of fallback text. The scale is fluid: every step is a clamp(), so nothing needs a breakpoint, and body text never drops below 16px.

--step-6 · display · 2.7–5.1rem · -0.038em · word-spacing .1em

Grow forests

--step-5 · h1 · 2.35–4.35rem

A farm that pays for a forest

--step-4 · h2 · 1.95–3.3rem

Numbers we will defend

--step-2 · h3 · 1.22–1.55rem

Native woodland

--step-1 · lead · 1.08–1.24rem · 1.62

Every vegetable box we sell funds native woodland, planted by hand and monitored for three years.

--step-0 · body · 1.0–1.06rem · 1.62

Most reforestation is funded by people a long way from the land. We do it the other way round: the farm earns, the woodland grows, and the people who plant it live twenty minutes away.

08

Forms & capture

Every form on the site runs through one handler: validate on blur, describe errors in words, never rely on colour alone, and confirm success politely. Add data-capture="type" to a form and it is wired up.

Hints sit below the control.

Enter a valid email address, e.g. name@example.com

<!-- a fully wired capture form -->
<form data-capture="newsletter" data-redirect="thank-you.html">
  <input name="email" type="email" required>
  <button type="submit">Join</button>
</form>

Submissions are validated, stored in localStorage and replayed on the confirmation page. Set Rootstock.Forms.config.endpoint to POST them to a real collector instead — no markup changes.

09

Motion

Motion explains change: where something came from, that it responds to you, or that it has left. Five durations, four easings, and one absolute rule — all of it disappears under prefers-reduced-motion.

Durations

--dur-1 160ms · state change
--dur-2 280ms · hover, buttons
--dur-3 450ms · panels, cards
--dur-4 700ms · entrances
--dur-5 1.1s · headline wipes, image zoom

Easings

--ease-out · general interface
--ease-expo · entrances, long travel
--ease-spring · anything that should feel alive
--ease-in-out · looping ambient motion

Accessibility standards

RuleStandard applied
Text contrast4.5:1 minimum, both themes; large text 3:1
Focus2px solid brand outline, 3px offset, never removed
Touch targets44×44px on buttons and form controls; 24×24px minimum on inline text links (WCAG 2.2 AA)
MotionFully disabled under prefers-reduced-motion
FormsReal labels, text errors, aria-invalid, polite status region
LandmarksOne main, labelled navs, skip link on every page
ImagesMeaningful alt text; decorative art marked aria-hidden
KeyboardTabs, accordions, drawer and carousel all operable

11

Using the system

The whole site is three files plus content. There is no framework and no build step for the CSS or JavaScript.

assets/css/style.cssTokens, components, motion. The only stylesheet.
assets/fonts/*.woff2Plus Jakarta Sans, self-hosted as one variable file per subset.
assets/js/site.jsTheme, nav, reveals, counters, tabs, accordions, carousel, parallax.
assets/js/forms.jsValidation, capture, donation calculator, confirmation page.
tools/build.pyWraps src/*.html fragments in the shared header and footer.
tools/gen_art.pyRegenerates every illustration from the palette.
# edit a page, then
python3 tools/build.py
# change the palette, then
python3 tools/gen_art.py
